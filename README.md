# Prisme

Un jeu de rythme en étoile : les notes jaillissent d'un cristal et filent vers quatre socles. Frappe la bonne flèche quand elles s'y posent. Les 200 morceaux de Rythme, ou ta propre musique.

Les notes partent du cristal central vers quatre socles en losange. Frappe la flèche du socle au moment où la note s'y pose, maintiens les notes longues. Plein écran pendant la partie, difficulté calculée, note de S à D.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Prisme → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
